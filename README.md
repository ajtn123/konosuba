## 线上食用

浏览器访问 <https://ajtn123.github.io/konosuba/>。

## 本地食用

1. 下载 gh-pages 分支
    - 使用 `git clone`
    - 下载并解压 [zip 文档](https://github.com/ajtn123/konosuba/archive/refs/heads/gh-pages.zip)，将文件夹重命名为 `konosuba`
2. 在含有 `konosuba` 的上级目录启动 http 文件服务器
    - `python -m http.server 8080`
    - `python3 -m http.server 8080`
    - `npx http-server`
    - `pnpm dlx http-server`
3. 浏览器打开 `http://localhost:8080/konosuba/`

### TL;DR

```
git clone --branch gh-pages --single-branch https://github.com/ajtn123/konosuba.git
python -m http.server 8080
start http://localhost:8080/konosuba/
```
